# Your first-website SEO checklist

Use this checklist as a practical starting point. Adapt it to your website and audience.

## Content and search intent
- [ ] Define one main audience question for each important page.
- [ ] Write a clear, descriptive page title and a useful meta description.
- [ ] Use one clear main heading and logically ordered subheadings.
- [ ] Include original examples that help answer the visitor's question.
- [ ] Link to relevant pages using descriptive link text.

## Website experience
- [ ] Check navigation, text and forms on a phone.
- [ ] Compress large images and add meaningful alternative text.
- [ ] Fix broken links and missing pages.
- [ ] Make important pages reachable through site navigation.
- [ ] Confirm that pages intended for search are not marked noindex.

## Review and improvement
- [ ] Record the pages you updated and why.
- [ ] Review search performance using your configured analytics tools.
- [ ] Prioritise improvements that make pages more useful to visitors.
